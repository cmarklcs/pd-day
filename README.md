# November 6 PD Day

Live schedule for the Lausanne Collegiate School PD Day, with resource links that presenters add during their sessions.

- `index.html` holds the schedule (the `SCHEDULE` and `JOINT` data near the top of the script) and the page itself.
- Links are stored in a private Google Sheet. An Apps Script web app attached to it reads and adds them. Its URL goes in `API_URL` in `index.html`.
- Anyone can add a link. To remove any link, delete its row in the sheet.
